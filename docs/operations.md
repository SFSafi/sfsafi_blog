# 维护、备份与回滚

正文目前仍含示例内容，已部署 D1 互动、文字管理、评论直接公开与站主管理。统一管理中心的操作见 [admin.md](admin.md)；自定义域名管理路径受 Access 保护，站主真实邮箱登录未代为验收，正文媒体上传按用户指示暂缓。

## 代码

分支 stage-a 保存当前原型。回滚代码时在托管平台重新部署已验证的旧提交，或通过 Git revert 生成可追踪的修复提交。CI 构建产物只保留 7 天，用于诊断，不作为内容备份。

## 内容与媒体

Git 历史仅覆盖示例和源代码，不能替代未来数据库与媒体备份。尚未配置生产备份周期、保留时间或验证恢复。B/C 阶段按选定服务及预算定义导出频率、媒体对象备份、管理员权限、加密与恢复演练，记录具体恢复结果后才称备份有效。

## 日志与故障

原型构建错误查看 CI 输出；视频/图片失败在页面有重试提示。已存在 Worker API；生产错误采集/告警尚未正式配置。CMS 发布失败、上传超限、权限边界、Webhook 验签和版本上线状态属于后续验收，不以原型测试替代。

## D1 互动与个人资料

生产 D1 已绑定并经真实请求验证；备份/恢复仍未验收。使用 Cloudflare D1 网页提供的导出/恢复能力或受支持的 D1 export 命令保留 SQL 导出；数据库含头像 BLOB、昵称、地点与统计，不能用 Git 代替。周期/保留时间将在账户配置后确定。

本地测试使用持久 SQLite 数据，并验证 Workerd 重启后头像昵称与地点保持；不等同云端恢复验收。头像更新保留旧对象版本，不立即删除原头像数据；公开旧 URL 仍可能可访问，因此只上传允许公开的头像。正式清理前需确认保留/恢复策略。匿名访客哈希不会公开，Cookie 有效期 90 天；服务端统计并非准确的自然人 UV。

代码回滚前检查旧版本是否兼容已应用的迁移；迁移均为新增，禁止直接删除生产数据来回滚代码。统计写入失败和未配置错误展示重试，不生成假计数。

## 后续 QQ Bot 运维

按 next-features.md 交付独立 Bot 的健康检查、自动重启、持久投递任务、日志与故障重试、订阅数据/凭据管理及备份恢复。当前没有已部署 Bot，不能把代码或开发机进程当作持续运行保证。

## 文字与评论、订阅任务

contents 的正文/草稿/版本/回收站标记、comments 的状态/删除标记、site_settings 的网站文案、comment_email_contacts/comment_mail 的私有通知数据、publication_outbox 的接收状态及 qq_* 的订阅/投递均属于 D1 数据，必须与原资料/统计一并备份。代码回滚不恢复文章或网站文案；归档、回收站与评论删除标记保留历史记录，不等于物理删除。文章从回收站恢复为草稿后需重新发布；被删除时取消的邮箱订阅不会恢复。公开页面 no-store 避免缓存旧正文/文案；保存冲突要重新载入而不是覆盖。实际云端备份/恢复与真实 QQ 投递仍未验收。
