# 字体与媒体来源

- MiSans 字体来自小米；官方来源 https://hyperos.mi.com/font/zh/ 。通过 npm `misans@5.0.0` 的官方字符范围子集 WOFF2 CSS 引入 Medium 500；unicode-range 按需加载，font-display:swap 与系统字体回退。
- 字体适用《MiSans 字体知识产权许可协议》，不是 npm 包脚本的 Apache License。协议链接：https://hyperos.mi.com/font-download/MiSans%E5%AD%97%E4%BD%93%E7%9F%A5%E8%AF%86%E4%BA%A7%E6%9D%83%E8%AE%B8%E5%8F%AF%E5%8D%8F%E8%AE%AE.pdf 。免费使用须注明 MiSans，不独立售卖字体。项目不修改字体；包提供的既有子集化资源直接使用。
- 字体处理脚本版权为 DSRKafuU，Apache-2.0，许可副本在 public/licenses/misans-package.txt。详见包 README 的 Copyright (Fonts) 和 License (Scripts)。
- 头像和四幅 SVG 插画为本项目创建的示例素材，不代表站主真实头像、照片或身份。
- flower.mp4 来自 MDN 公共领域/CC0 示例：https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4 。仅用于视频播放验收。
