# 阅读、发现与订阅

## 信息流与媒体

首页“全部 / 短动态 / 图片与视频 / 长文”可以按内容类型浏览；每个入口有独立可复制链接，分页保留筛选。标签行来自真实公开内容，可进入标签目录继续寻找记录。没有添加推荐算法或访客行为追踪。

卡片展示手动摘要或正文的短预览，完整文字通过稳定详情链接阅读。操作区包含真实阅览、互斥赞踩、可见评论总数、链接与图片分享；评论总数包含公开回复，删除父评论后相关回复不会继续计数。提交评论后更新数量。两张/四张配图采用两列，其余组图沿用三列；单图保留比例，图片弹窗支持左右滑动、箭头按钮和键盘。

## 长文

文章详情显示约略阅读分钟数和文字数量。Markdown 标题生成唯一段落 ID；有多个标题时展示可折叠目录，点击链接可以定位，复制带锚点地址可分享对应段落。顶部进度条按正文滚动更新，“回到开头”在滚动后出现。阅读时间是按中文/词数估算，视频时长不计入。

目录标题、代码块、文章与评论正文不会被站点文案设置替换。详情末尾最多 3 条相关公开内容，共同标签优先，其次较新发布时间；草稿、回收站与当前文章不进入相关列表。标题序号会随段落调整而改变，文章自身的稳定链接保持不变。

## RSS

入口 https://sfsafi-blog.uk/subscribe/ ，订阅地址 https://sfsafi-blog.uk/rss.xml 。复制到支持 RSS 的阅读器即可使用，无需本站读者账号。Feed 包含最近 50 条公开记录的标题、摘要、标签、首次发布时间和稳定链接；置顶不会挤占新记录的顺序，修改不重置发布时间或 GUID。

RSS 与站点地图由当前 D1 数据生成。撤回/删除后立即从新响应移除，草稿不进入公开 Feed；已经被阅读器保存的内容由该阅读器管理。没有新增全站邮件订阅，评论回复邮件仍按 comment-email.md 的独立流程。

## 搜索引擎与链接预览

- `/sitemap.xml` 输出公开页面、标签和文章链接及最后修改时间。
- 当前单份地图最多 10000 条内容和 50000 个总链接；超限返回错误，需要拆分地图，不截断内容。
- `/robots.txt` 指向站点地图，不鼓励抓取后台/API/内部模板；实际安全边界仍是 Access、站主身份与发布状态。
- 页面提供 canonical、Open Graph/Twitter 标题与介绍。文章详情另含 BlogPosting/SocialMediaPosting JSON-LD、作者、首次发布和修改时间。
- 规范域名默认 `https://sfsafi-blog.uk`；Worker 变量 `PUBLIC_SITE_URL` 只接受无路径、无凭据的 HTTPS origin。它独立于推送/邮件使用的 SITE_URL。

保存网站名称/介绍会同步页面元数据；用户正文保持原值。链接预览和搜索收录取决于外部平台的抓取与缓存，本轮验证的是正确输出，未代为申请或验证实际收录。静态原型只用于回退；动态 RSS、评论数量和管理持久化需 Worker/D1。
