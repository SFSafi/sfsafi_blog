## 修改网站文案

1. 打开“网站文案”，填写网站名称，或搜索页面当前显示的默认文字。
2. 选择读者界面、管理界面或提示与交互分类，编辑需要修改的项目。相同默认文字共用一项设置。
3. 默认只应用到读者界面；若希望后台文字也变化，勾选“也应用到管理界面的文案”。仅后台使用的自定义文案不会发送到公开页面。
4. 点击“保存文案”，再打开或刷新网站即可看到。站名同步更新导航品牌、顶部标记和浏览器标题；文章自己的标题保持不变。

每项最多 4000 字，按纯文本显示；网站名称最多 120 字。动态文案中的 {0}、{1} 等是昵称、数量或其他运行时值，必须保留各占位符，可调整顺序。“恢复这一项”和“全部恢复默认”需再保存才生效。搜索/切换分类会保留尚未保存的修改；离开页面会提示未保存内容。另一管理页已先保存时返回版本冲突，需重新载入。

头像、昵称、简介在“头像与资料”里编辑；文章正文/标题/标签/地点在“文章与动态”里编辑。访客评论、搜索结果正文、代码块和表单输入不会被全站文案设置替换。Cloudflare 登录页、邮件通知模板属于各自服务，不在网站文案目录里。

文案保存在 D1 的 site_settings 表，部署不会重置设置。构建脚本从源码与 HTML 生成默认文案目录，以规范化默认文字的 SHA-256 摘要作稳定键；如果后续代码修改了某项默认文字，目录会生成新键，该项需重新设置。默认文字不变的自定义设置继续生效。

## 发布、修改与删除

- 新建内容可以先保存草稿，也可直接点“发布”，后台先保存当前内容再发布。
- 从“文章与动态”点“编辑”，修改已发布内容后点“保存”，立即更新公开页面、列表与站内搜索，不需要重新部署。稳定链接和首次发布时间保持不变。
- “撤回为草稿”将文章撤下，仍可编辑并重新发布。
- “删除”需要确认，随后移入回收站；公开正文、列表、搜索与评论入口不再展示。回收站内容不能直接修改/发布，重新部署也不会重新导入被删除的样例。
- 筛选“回收站”后点“恢复为草稿”，内容仍为私有草稿，需要再次点击发布才会公开。保留正文、稳定 ID/链接、统计及历史评论；不重复创建首次发布的 QQ 事件。删除取消该内容相关的评论邮箱订阅及排队邮件，恢复不会重建邮箱订阅。

当前删除是可恢复操作，没有永久清除正文/媒体的按钮。历史评论中已删除或隐藏的记录也不会因恢复文章重新公开。多页编辑发生冲突会拒绝覆盖较新版本。R2/正文媒体上传、真实 FFmpeg 服务、QQ 和邮件服务的配置状态见各自文档，管理页面不代表这些外部服务已启用。
